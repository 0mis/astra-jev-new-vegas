# Controller contract

The local pipeline is game telemetry -> compact Jev choices -> guarded normal input -> fresh observation and outcome feedback. Jev chooses useful game actions. Astra provides planning, capability development and proactive recovery to improve speed and reliability. Jev does not see the desktop directly. Read-only memory observations use version-specific layouts and may become stale while being read.

`planner_mailbox.py` publishes compact observations and accepts advisory plans without blocking the Jev loop. Advice is bound to the current cell/quest/objectives and expires; a stage change rejects old advice. This uses the existing Codex task, with no additional paid planner model or competing controller. `gameplay_skills.py` retains short lessons from observed failures. These are authored interface/recovery improvements, not model-weight training.

Floor-route actions execute up to three seconds of fresh, guarded steering per decision. The policy receives movement availability, target motion, route progress, elapsed time and measured outcomes. Disabled controls and unrelated furniture are filtered from candidate actions; waits are omitted when an explicit distant objective is traversable. Manual movement and alternate route choices remain. Missing capabilities or repeated stalls still request assistance.

The recorded campaign completed the main story with supervised travel, dialogue, combat and recoveries. Loaded meshes share only matching floor edges; separate interior coordinate frames are never combined. Door destinations connect quest targets across cells, and paired-door lock checks help prefer unlocked entrances. Modal notices and tutorials have bounded controls, while inventory, equipment, healing, VATS and scoped dialogue use dedicated helpers. The policy reports recent outcomes, actual camera orientation and disabled controls. Cooldowns, progress checks and the independent watchdog request a handoff when an action or route stops advancing. Completion of this campaign does not establish reliable unattended play or complete menu and failure coverage.

Code calculates geometry and executes Jev's selected action. The navmesh graph gives normal movement waypoints; it does not move the player itself. Normal keyboard and mouse input are the only game-control mechanism. Camera position and orientation are observed from the world scene graph rather than inferred from a fixed eye height or seated player-body rotation.

Persistent-cell metadata keeps an unloaded quest target in its correct worldspace. Partial paths advance through reachable loaded geometry toward distant objectives. Route smoothing clips proposed segments against the floor corridor and a height band, rejecting gaps instead of blindly skipping corners. It does not account for every dynamic obstacle.

A bounded aim-and-fire skill tracks a loaded, living target and refreshes its rendered position during up to three seconds of normal shooting. It stops when the target dies, the magazine empties or the UI changes. Eligible targets come from an observed combat relationship or a supported quest objective. Health, equipped ammunition and injury observations inform healing and equipment choices. A separate guard restricts explosive fire at close range; VATS remains an option when useful. These version-specific checks still require supervision and do not prove safe targeting in every encounter.

Observe before dispatch; discard stale model decisions or changed control sets. Log a unique request identity before input. After uncertain execution, inspect state rather than replaying the action. Never run competing controllers or Jev clients. Always release held inputs, even after failure. A handoff attempts a verified normal pause only in a recognized foreground gameplay state; it must report when that cannot be established.

Recording binds to a verified FalloutNV process and exact HWND. Window title alone is ambiguous because the launcher shares the title. Capture video and system playback audio separately, preserving wall-clock launch/start timestamps for later alignment. The input gate checks fresh increasing encoded video frames and AAC timestamps, matching process identity, positive captured audio and zero discontinuity warnings. These checks are evidence of current progress, not a guarantee against every capture fault.

Audio capture uses a two-second device buffer and a bounded encoding queue. A separate monitor handles filesystem/window checks and status publication. Brief Windows sharing errors get a bounded retry of the status-file read only; persistent failures still stop input. Gameplay actions and uncertain model requests are never automatically replayed by this recovery.

Preserve source footage, segment order, warnings and save checkpoints. The campaign ending is verified, and private editing is in progress. Public commentary describes objectives, observations and actual actions; retrospective narration is labeled separately and never presented as private reasoning. The final media still require complete visual and audio privacy review before publication. A completed historical Fallout run or existing user achievement is not evidence for this campaign.
